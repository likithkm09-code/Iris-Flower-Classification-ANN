1. Forward Propagation Equation

For each layer $l \in \{1, 2, 3\}$:

$$Z^{[l]} = A^{[l-1]} W^{[l]} + b^{[l]}$$ $$A^{[l]} = g^{[l]}(Z^{[l]})$$

Where $g^{[1]}, g^{[2]}$ are ReLU, and $g^{[3]}$ is the Softmax operator.

2. Softmax Activation Function

Converts arbitrary logits into valid normalized class probabilities:

$$\sigma(Z_i) = \frac{e^{Z_i - \max(Z)}}{\sum_{j=1}^3 e^{Z_j - \max(Z)}}$$

Includes $\max(Z)$ subtraction to guarantee numeric stability against exponential overflow.

3. Categorical Cross-Entropy Loss

Penalizes confident misclassifications logarithmically:

$$\mathcal{L} = -\frac{1}{N} \sum_{i=1}^N \sum_{k=1}^3 y_{i,k} \log(\hat{y}_{i,k}) + \frac{\lambda}{2} \sum_l \|W^{[l]}\|_F^2$$

With $L_2$ weight regularization ($\lambda = 0.001$) to prevent over-fitting.

4. Backpropagation Gradient

Combined Softmax and Cross-Entropy loss derivative simplifies to:

$$\frac{\partial \mathcal{L}}{\partial Z^{[3]}} = \frac{1}{N} (\hat{Y} - Y)$$ $$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = (A^{[l-1]})^T \frac{\partial \mathcal{L}}{\partial Z^{[l]}} + \lambda W^{[l]}$$

Passed recursively through hidden layers using the activation Jacobian.

Q1: Why use an Artificial Neural Network (ANN) instead of a simple Linear Classifier?
Iris Versicolor and Virginica have slight morphological overlap in feature space. While Setosa is linearly separable, separating Versicolor from Virginica requires a non-linear decision boundary. The multi-layer ANN with ReLU activations learns high-order non-linear combinations of sepal and petal ratios.
Q2: Why is Feature Standardization (Z-score) necessary before feeding data to the ANN?
Features have varying numerical scales (e.g. Sepal Length spans 4.3–7.9 cm while Petal Width is 0.1–2.5 cm). Without scaling, the gradient updates would oscillate along features with larger variance, slowing down or preventing optimal convergence. Z-score scaling ($z = \frac{x - \mu}{\sigma}$) centers gradients for smooth Adam optimization.
Q3: What role does the Adam Optimizer play over standard SGD?
Adam (Adaptive Moment Estimation) maintains both exponentially decaying first moments (momentum) and second moments (uncentered variance of gradients). This dynamically scales the learning rate per individual parameter, allowing swift progress across flat plateaus and avoiding divergence in steep ravines.
Q4: Why use He (Kaiming) initialization for ReLU layers and Xavier for Softmax?
Because ReLU zeros out all negative inputs, it reduces variance by half. He initialization scales weights by $\sqrt{2 / n_{in}}$, preventing activation variances from exploding or vanishing across deep forward passes. Xavier scales by $\sqrt{2 / (n_{in} + n_{out})}$, optimal for symmetric linear/softmax transitions.
